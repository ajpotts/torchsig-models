Summary
Investigate how TorchSIG spectrogram inputs should be normalized for EfficientNet training and inference. Per-sample normalization is now optional and disabled by default because it removes differences in absolute power, noise-floor level, and SNR between examples. EfficientNet still benefits from a stable and consistent input distribution, so training-dataset normalization may be a better default.
This ticket is an investigation. It should produce an evidence-based recommendation and implementation plan; it does not assume that dataset-level normalization is necessarily superior for every TorchSIG task.
