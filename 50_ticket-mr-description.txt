## Summary

- add shared HPO helpers for complete training metadata and combined CSV plus
  Lightning MLflow logging, used by both EfficientNet-1D and EfficientNet-2D
  searches when `--enable-mlflow` is set
- attach Lightning to the MLflow run already created by the shared Optuna
  utility, avoiding duplicate runs and leaving run finalization with the HPO
  lifecycle manager
- record the complete trial configuration, dataset IDs/lengths/seeds, storage
  backend, optimizer, scheduler, epoch metrics, and final evaluation metrics
- fall back to CSV-only logging with a warning if MLflow initialization or
  metric/parameter logging fails
