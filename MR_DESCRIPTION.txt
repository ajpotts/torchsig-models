Title: Align spectrogram classifier size with generated dataset classes

Summary

- Build the spectrogram EfficientNet classifier using the generated dataset's
  class list instead of the global TorchSig signal list.
- Use the same generated class count for training and evaluation metrics.
- Update training tests to cover subset and all-signal configurations while
  preserving the dataset's label-to-name mapping in returned metadata.
