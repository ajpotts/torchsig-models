Title: Train directly from pre-generated TorchSig 2.2 storage backends

Summary

This MR lets the training modules use the storage backend declared in a
TorchSig 2.2 dataset configuration. A pre-generated homogeneous HDF5 dataset
can therefore be trained from using its original YAML configuration, without
manually passing Python reader and writer classes. Legacy HDF5 remains the
default for configurations that omit `storage`.

Changes

- Resolve legacy, packed, and homogeneous writer/reader pairs from
  `storage.writer` in each dataset configuration.
- Use `storage.options` when reopening or generating the configured dataset.
- Keep file_handler, file_reader, and file_handler_options as explicit Python
  API overrides.
- Forward the storage configuration consistently to train, validation, and
  test DatasetCreator instances.
- Reopen each generated split with the reader paired with the selected writer.
- Expose the same storage options through the EfficientNet IQ and spectrogram
  training entry points.
- Add --homogeneous-hdf5 to the toy spectrogram classification example.
- Raise the minimum TorchSig dependency from 2.1.1 to 2.2.
- Add unit coverage for defaults and option forwarding.
- Add a real homogeneous HDF5 round-trip test that verifies sample values,
  labels, shape, and complex64 dtype preservation.

Usage

Set the backend in the dataset YAML used to generate and train the dataset:

    storage:
      writer: homogeneous
      options:
        compression: null

Then pass that YAML through the normal EfficientNet IQ or spectrogram training
CLI. The training path selects HomogeneousHDF5Reader automatically. Library
callers may still override the classes and writer options explicitly.

Compatibility

- Legacy HDF5 remains the default.
- Existing calls require no changes.
- Homogeneous HDF5 is appropriate only when every top-level sample has the
  same shape and dtype.
- Existing static datasets remain readable through legacy configurations.
- A pre-generated dataset must be paired with the same storage declaration
  that was used to create it.

Validation

- ruff check on all changed Python files: passed.
- Focused pytest suite: 57 passed.
- Real homogeneous HDF5 complex64 round trip: passed.
- Example command-line help smoke test: passed.
- git diff --check: passed.
