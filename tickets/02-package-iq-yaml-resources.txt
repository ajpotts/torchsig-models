Title: Include IQ EfficientNet YAML resources in distributions

Criticality: High
Estimated effort: Low
Type: Packaging bug

Description:
The package-data configuration includes training parameter and search
configuration YAML files for spectrogram EfficientNet only. The IQ EfficientNet
training, inference, and hyperparameter-search modules also load default YAML
files relative to their installed module path.

This works from a source checkout but may fail with FileNotFoundError after
installation from a wheel or source distribution if those IQ YAML resources are
not included.

Evidence:
- pyproject.toml declares package data only for
  torchsig_models.models.spectrogram_models.efficientnet
- torchsig_models/models/iq_models/efficientnet/efficientnet1d_train.py loads
  training_params/<model>.yaml
- efficientnet1d_hyperparameter_search.py loads search_configs/<model>.yaml

Proposed resolution:
Add an equivalent package-data entry for
torchsig_models.models.iq_models.efficientnet, covering both training_params and
search_configs YAML files.

Acceptance criteria:
- All six IQ EfficientNet YAML files are present in a built wheel.
- Install the wheel into a clean environment and successfully call the default
  IQ training-parameter and search-configuration loaders.
- Add an automated distribution-content or installed-package smoke test.
