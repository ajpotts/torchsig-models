Title: Add default training parameter files for EfficientNet-1D
Type: Bug
Priority: High

Description
-----------
The EfficientNet-1D training and inference entry points look for default
parameter files under:

    torchsig_models/models/iq_models/efficientnet/training_params/

That directory and its expected efficientnet_b0.yaml, efficientnet_b2.yaml,
and efficientnet_b4.yaml files do not exist. Calling load_training_params()
without an explicit params_path therefore raises FileNotFoundError, and the
default CLI workflow cannot start.

Relevant code
-------------
- torchsig_models/models/iq_models/efficientnet/efficientnet1d_train.py
- torchsig_models/models/iq_models/efficientnet/efficientnet1d_inference.py

Proposed work
-------------
1. Add default YAML parameter files for EfficientNet-B0, B2, and B4 under the
   expected training_params directory.
2. Ensure the files are included in built source and wheel distributions.
3. Add tests that load each default file without supplying params_path.
4. Document the available parameters and defaults.

Acceptance criteria
-------------------
- load_training_params() succeeds for all three supported 1D model names when
  params_path is omitted.
- The 1D training and inference CLIs can use their default parameter files.
- The YAML files are present after installing a built wheel.
- Tests cover every supported model name.
